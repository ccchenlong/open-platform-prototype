03 模块 PRD · 创新支撑系统（开放平台）

  • 版本：v1.3 ｜ 责任人：周宇（占位） ｜ 日期：2026-10-29
  • 依据：01-analysis.md v2.1（r3）、02-clarify.md（D-01～D-03）、context/prd-template.md
  • 范围：开放平台门户（59）+ 开放门户管理（135），共 194 个功能点 / 11 个模块 / 18 个后台页面 另加 前台浏览端 4 页（D-01 新增，不计入 194 条，C-07）
  • 功能点明细见附录：03-prd-功能清单.md

1. 背景与目标

开放平台对外暴露能力（API、文档、资源、案例），但门户内容与文档长期依赖开发人员手工改代码，缺少可运营的后台。本期建设后台配置与运营能力，让四类分级管理员在各自权限与机构范围内自助维护，不触碰数据库与代码。

目标 1. 194 个功能点全部可操作，P0 134 条无阻断缺陷。 2. 打通主流程：配置首页区块 → 维护开放能力文档 → 接收处理工单 → 发布公告。 3. 权限按「角色 → 权限组 → 机构」三级生效，跨机构数据不可见。 4. 前台浏览端 4 页可访问，内容与后台配置一致（D-01）。

非目标 - 前台浏览端不做登录注册、在线调试、工单提交（D-01 边界） - 不做权限管理、系统管理、标签管理、通知待办四个子系统 - 不做移动端专属布局（仅响应式降级）

2. 用户与场景

角色 可进入的页面 数据范围 关键动作
分级管理员 P01–P18（本级） 本级及下级机构 分配下级管理员、配置本级首页与内容
应用管理员 P05、P11–P13、P16 所辖应用 维护所辖应用的开放能力、资源与文档
工作台管理员 P01–P09、P15、P18 本级工作台 维护首页区块、帮助与搜索配置
工单管理员 P14 本级工单 处理与审批工单
系统内置超管 全部（只读入口） 全局 授权管理员（A-02，本期只保留判定）

主流程：工作台管理员配置首页轮播与公告 → 应用管理员维护 API 文档与示例 → 工单管理员处理用户工单 → 分级管理员查看本级指标。

状态覆盖要求：每个页面必须具备正常、空、加载、错误、无权限五态。

4. 页面说明

前台配置区（开放平台门户）

P01 轮播图配置（7 条） - 元素：列表（缩略图、标题、跳转、排序、状态）、新增、编辑、删除、预览、查询 - 交互：新增/编辑走侧边抽屉；删除二次确认；置顶即时生效；图片上传限 2MB、1920×480 - 状态：无图时显示占位与上传指引；加载失败可重试

P02 通知公告配置（7 条）｜P03 接入步骤配置（6 条）｜P04 应用案例配置（6 条） - 元素：列表 + 新增/修改/删除/查看/查询，公告与应用案例另有置顶 - 公告：标题 ≤50 字、正文富文本、有效期起止 - 接入步骤：步骤序号、标题、说明，支持上下调序 - 应用案例：封面、名称、所属服务商、跳转链接

P05–P08 开放能力 / 开发资源 / 开发指南 / 帮助中心首页配置（各 7 条） - 元素：区块标题、展示条数、排序方式、内容选择（从对应管理模块挑选）、置顶 - 交互：内容选择弹窗支持按分类筛选；保存后前台区块即时更新

P09 指标展示（5 条） - 元素：五个指标卡（应用上架数、API 调用量、用户活跃数、通知数、应用待办数）+ 趋势 - 规则：数据口径与统计周期固定（近 30 天），不可在本页修改

后台管理区（开放门户管理）

P10 接入步骤管理（6 条）｜P15 帮助信息管理（13 条） - 元素：步骤/帮助条目列表、目录树、富文本编辑、发布与下线 - 规则：目录层级不超过 3 级；下线条目前台不可见但保留历史

P11 开发资源管理（13 条）｜P12 开发指南管理（13 条） - 元素：资源列表、文档目录树、文件上传（zip/pdf，≤50MB）、版本号、下载统计 - 规则：同目录下文件名不可重复；更新文件须填写版本与变更说明

P13 开放能力管理（42 条） - 元素：服务端 API / 客户端 API 两个 Tab，各自的 API 列表、文档目录、接口示例、错误码 - 规则：API 需绑定所属应用与版本；错误码全局唯一；示例与 API 版本必须一致 - 交互：API 详情左右分栏（左文档目录、右内容）；删除 API 前校验示例与错误码引用

P14 我的工单（15 条） - 元素：工单列表（编号、标题、提交人、状态、时效）、详情、处理、审批、导出 - 状态机：待处理 → 处理中 → 待审批 → 已完成 / 已驳回；驳回可重新提交 - 规则：超过 SLA 未处理标红；审批人不可与处理人同一人

P16 应用案例管理（8 条）｜P17 通知公告管理（11 条） - 元素：列表 + CRUD + 置顶 + 发布/撤回 - 规则：发布后才在前台可见；撤回保留记录

P18 全局搜索管理（14 条） - 元素：搜索范围配置（模块开关）、热搜词列表、排序、生效时间 - 规则：热搜词上限 20 个；同一词不可重复；停用后前台不再展示

前台浏览端（D-01 新增，4 页，不计入 194 条）

P19 门户首页（浏览） - 元素：轮播、公告、接入步骤、应用案例、开放能力入口、四个指标卡（不含「应用待办数」，该指标仅后台 P09 可见） - 数据：全部来自后台配置，只读；未配置的区块自动隐藏，不留空框 - 状态：全空时显示引导文案；接口失败显示占位并可重试

P20 开放能力文档（浏览） - 元素：左侧文档目录（≤3 级）、右侧正文、API 版本切换、错误码页签、示例代码复制 - 规则：目录结构与后台 P13 一致；版本不一致时正文顶部提示当前版本 - 状态：无文档显示空态；目录点击后正文平滑切换

P21 应用案例（浏览） - 元素：案例卡片列表、分类与服务商筛选、详情页 - 规则：仅展示「已发布且未下线」的案例；置顶按后台顺序 - 状态：无案例显示空态并提供返回首页入口

P22 全局搜索（浏览） - 元素：搜索框、热搜词、结果分组（文档 / 案例 / 指南 / 帮助） - 规则：热搜词来自后台 P18，停用词不展示；无结果给出推荐词 - 状态：搜索中显示加载；超时提示重试

5. 业务规则

编号 规则 前置条件 失败处理
R-01 权限判定顺序：角色 → 权限组 → 机构数据范围 用户已登录且被授权 无权限跳 P403 态并给申请入口
R-02 机构数据隔离：仅可见本级及下级机构数据 机构树已维护 越权请求返回空列表并记日志
R-03 删除保护：存在关联引用时禁止删除 先查引用（示例/错误码/文档） 阻断并列出引用方
R-04 排序规则：有置顶的对象置顶项优先、按置顶时间倒序，其余按更新时间倒序；无置顶的列表型（轮播、接入步骤）按排序值 1–99 升序 记录状态为已发布 / 已上架 排序异常回退默认排序
R-05 文档目录层级 ≤3 级，同级名称唯一 目录已存在 阻断并提示冲突项
R-06 发布/下线上线：发布前台可见，下线保留历史 内容校验通过 校验失败阻断并定位字段
R-07 工单状态流转仅允许前进，驳回可重提 工单存在且未终态 非法流转阻断并提示当前状态
R-08 审批人与处理人不可为同一人 工单进入待审批 阻断并提示更换审批人
R-09 文件上传限类型与大小，超限拒绝 已选文件 前端先校验，服务端二次校验
R-10 热搜词上限 20 个，同词唯一 新增热搜词 超限或重复阻断并提示

6. 异常处理

场景 触发 系统行为 用户提示 恢复
